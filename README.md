## Como participar

1. Leia [regras](docs/regras.md), desafio e [critérios de avaliação](docs/avaliacao.md).
2. Forme sua equipe conforme os limites que a organização publicar.
3. Trabalhe neste repositório ou no repositório de equipe indicado oficialmente.
4. Siga o [guia de submissão](docs/submissao.md) e entregue dentro do prazo.
5. Prepare uma demonstração acessível aos avaliadores.
