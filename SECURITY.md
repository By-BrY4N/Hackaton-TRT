# Segurança

- Nunca envie chaves, tokens, senhas, certificados privados ou arquivos `.env`.
- Use dados sintéticos ou conjuntos expressamente aprovados.
- Não acesse, extraia, publique ou teste dados e sistemas do TRT sem autorização explícita e escopo documentado.
- Se uma credencial for exposta, avise a organização pelo canal privado e revogue-a.
